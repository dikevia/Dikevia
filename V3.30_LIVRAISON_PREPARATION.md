# CFDT JURIS V3.30 — Livraison de préparation au développeur

## Ce qui a été modifié
1. `backend/app/orchestrator.py` : sans date des faits, l'IA n'est plus appelée pour une analyse juridique contextualisée. La date du jour ne sert qu'au repérage documentaire et cette limite est affichée.
2. `database/migrations/014_cgfp_snapshot_source_type.sql` : type de source dédié `CGFP_SNAPSHOT`.
3. `database/migrations/rollback/014_cgfp_snapshot_source_type.down.sql` : rollback associé (à exécuter uniquement après traitement des lignes `CGFP_SNAPSHOT`).
4. `scripts/import_cgfp_to_legal_corpus.py` : import article par article, avec validation SHA-256 du PDF, contrôle du nombre d'articles, unicité, pagination, import idempotent et dates d'effet laissées inconnues.
5. `backend/tests/test_v330_legal_preparation.py` : tests de non-régression.
6. `docs/36_V3_30_LEGAL_ENGINE_PREPARATION.md` : documentation et procédure.

## Vérifications réalisées
- Suite complète backend : **135 réussis, 2 ignorés**.
- Contrôle à blanc de l'import : **4 242 articles validés**, SHA-256 du PDF conforme.
- Compilation Python des fichiers modifiés : réussie.
- Aucun accès à PostgreSQL, PISTE, Keycloak ou à l'environnement de production n'a été utilisé.

## Consignes au développeur
1. Sauvegarder la base de test.
2. Appliquer la migration 014 en environnement de test.
3. Exécuter le script avec le compte d'ingestion dédié et `--apply`.
4. Contrôler les 4 242 documents et leurs versions, le nombre de chunks, les doublons et les erreurs.
5. Tester la recherche par référence (ex. L4), par mots-clés et dans l'orchestrateur.
6. Exécuter les tests PostgreSQL/RLS avec les DSN de test : les deux tests ignorés dans notre environnement doivent devenir exécutés.
7. Fournir les journaux d'import, le résultat des tests et les preuves de validation avant toute promotion.

**Attention juridique :** l'import du snapshot ne rend pas le texte officiellement vérifié et ne renseigne aucune période d'effet. Les lignes sont `CGFP_SNAPSHOT`, `IMPORTED_UNVERIFIED`, statut `UNKNOWN`. Les versions officielles et leur temporalité doivent être récupérées et contrôlées séparément via les sources officielles.
